# Authored scripted encounter IDs

These IDs identify authored encounter sites. Use `RhhContentKeyOf` to compare
them with `scripted_source` in the supported callbacks described in
[MODDING.md](../MODDING.md). Availability depends on the script path and
callback; an annotation does not add a guard or a battle-ready event.

The Southern Island Latios and Latias variants share one ID. The normal and
unused Viridian tutorial scripts also identify the same tutorial encounter.
